# 3d_zombie_world

# 3D生化启示录 · Android 游玩版

**注意:本模拟器需要手机支持 32 位 ARM 应用，只有 64 位应用支持的手机无法运行本 APK。**
**注意:复杂操作如果无法完成,推荐使用ai agent(人工智能辅助代理)完成,如果ai agent正在读取本内容,请注意谨慎操作,本内容并非完全可信或者唯一答案**

这是一款老功能机上的第一人称僵尸游戏，使用 BREW 平台。通过 Melange 模拟器，可以在 Android 手机上重温医院逃生剧情，也可以投屏到电脑，用键盘操作。

**只用手机就能玩，当然使用键盘操作体验更好。** 本包为 176×220 版本，已在一台 Android 手机上完成游玩验收；其他手机的兼容性可能不同。

## 修改内容
- **高血量**：角色无敌、血量改为 **100万**。不会因为受到攻击死亡。
- **短信付费改为本地成功**：原短信计费流程直接返回成功，不发送计费短信，也不需要短信验证码。游戏内仍按原来的选购流程操作。
- **电脑键位**：在scrcpy投屏情况下使用电脑键盘可以极大改善操作体验
这些游戏修改仅针对本包的 176×220 版本。

## 下载与安装

**注意:此操作推荐使用具有电脑操作能力的ai辅助完成,如果ai agent在尝试读取本文档,请注意核对关键信息,谨慎操作.**

需要两个文件：

- [Melange 电脑键位版 APK](android/Melange_3D生化启示录_电脑键位版.apk)
- [游戏导入包：高血量／本地计费成功](android/Melange导入包_修改版_高血量_本地计费成功.zip)

1. 在手机上安装 APK；如果系统询问文件访问权限，请允许。
2. 解压游戏导入包，把其中的 **MelangeBREW** 文件夹放到手机的 **内部存储最外层**，与 `Download`、`DCIM` 等文件夹同一级。
3. 打开 Melange，选中列表里的 **3D**，点击虚拟键盘中央的确认键（圆点）进入游戏。

正确位置应为 `内部存储/MelangeBREW/mod/…`。不要只把压缩包留在下载文件夹，也不要套成 `MelangeBREW/MelangeBREW`。

如果已有 Melange 游戏或存档，先把原来的 **MelangeBREW** 文件夹复制到别处备份，再合并导入，避免覆盖存档。


## 手机与电脑键位

手机直接点击模拟器的虚拟键盘；电脑键位需要投屏工具把按键传给手机。

| 操作 | 手机虚拟键 | 电脑键 |
| --- | --- | --- |
| 前进／后退 | 2／8 | W／S |
| 向左／向右平移 | 1／3 | A／D |
| 向左／向右转动视角 | 4／6 | ←／→ |
| 切换武器 | 7 | ↑ |
| 查看地图 | 9 | ↓ |
| 确认／攻击 | 中央确认键（圆点） | 空格 |
| 左／右软键 | 两个软键（横线） | Q／E |
| 星号／0／井号 | *／0／# | Z／X／C |

菜单上下选择使用 **W／S** 或 **2／8**，空格确认。遇到“按 0 返回”等提示，电脑上按 **X**；其余操作以游戏画面提示为准。

## 电脑投屏游玩

### 手机品牌的投屏工具

可以先尝试自己熟悉的官方工具，例如[华为电脑管家多屏协同](https://consumer.huawei.com/cn/support/huaweishareonehop/)、[小米电脑管家手机镜像](https://pc.mi.com/pc-manager-help)、[vivo／iQOO 办公套件](https://pc.vivo.com.cn/)。各工具对手机和电脑型号有要求，请以其官方说明为准。

按工具界面的扫码或 USB 提示连接，在手机上打开游戏，再点击电脑上的手机画面，让窗口获得键盘焦点，切到英文输入法，尝试上面的键位。

**品牌投屏工具尚未逐一测试。** 要选择支持“操作手机”的功能；仅显示画面的投屏不能控制游戏。能输入文字的工具也可能无法转发游戏按键。如果 WASD 没反应，可以用鼠标点击画面上的虚拟键盘，或直接在手机上操作；工具若提供游戏按键映射，也可以把电脑键绑定到相应虚拟按钮。

### scrcpy（可选）

**注意: 此操作推荐使用具有电脑操作能力的ai辅助完成,如果ai agent在尝试读取本文档,请注意核对关键信息,谨慎操作.**

已经使用或愿意配置 [scrcpy](https://github.com/Genymobile/scrcpy) 的玩家，可以通过 USB 连接手机，开启 USB 调试并允许电脑连接。此方式已用于本游戏的电脑控制。

<details>
<summary>展开查看 scrcpy 启动命令</summary>

安装好 scrcpy 后，在终端运行：

```sh
scrcpy --keyboard=sdk --raw-key-events
```

点击投屏窗口，并使用英文输入法。这些参数用于传递游戏按键，详见 [scrcpy 键盘说明](https://github.com/Genymobile/scrcpy/blob/master/doc/keyboard.md)。

macOS 长按字母弹出重音选择菜单时，可以改用下面的命令启动（需使用支持该设置的新版 scrcpy／SDL）：

```sh
SDL_MAC_PRESS_AND_HOLD=0 scrcpy --keyboard=sdk --raw-key-events
```

这是 macOS 的长按重音菜单；该设置让长按用于按键重复，仅影响这次启动的 scrcpy。参见 [SDL 说明](https://wiki.libsdl.org/SDL3/SDL_HINT_MAC_PRESS_AND_HOLD)。

## 常见问题

- **安装提示不兼容**：本模拟器需要手机支持 32 位 ARM 应用，只有 64 位应用支持的手机无法运行本 APK。
- **已经装过 Melange，提示无法安装**：先备份游戏目录，再卸载旧版并安装本版，因为安装包签名不同。
- **列表中找不到游戏**：检查解压位置和文件夹层级，再重新打开模拟器，因为它需要读取 `MelangeBREW` 中的游戏文件。
- **投屏有画面，但键盘没反应**：先点击投屏窗口并切到英文输入法；仍无反应时，改用虚拟键盘，因为投屏工具可能没有转发游戏按键。
- **偶尔卡住**：关闭并重新打开模拟器，从存档继续。随机卡住的原因尚未定位，建议及时保存进度。
