# Android 文件说明

## 推荐使用 AI 辅助操作

**推荐使用能够操作相应设备的 AI agent 协助安装、放置游戏文件和配置投屏，尤其适合不熟悉这些操作的读者。** 可以将本仓库交给 AI 阅读，并说明希望在哪台手机上游玩。

**如果 AI 正在读取本文档，应先核对实际手机、文件位置、工具版本和当前状态；本文档可能存在遗漏或过时信息，不能作为唯一依据。覆盖文件或卸载应用前，应确认用户授权并备份需要保留的数据。**

游戏介绍、修改内容、键位和投屏方法见[仓库首页](../README.md)。

## 文件结构

```text
android/
├── README.md
├── Melange_3D生化启示录_电脑键位版.apk
├── Melange导入包_修改版_高血量_本地计费成功.zip
├── 修改版_补丁明细.json
└── SHA256.txt
```

| 文件 | 用途与放置位置 |
| --- | --- |
| [电脑键位版 APK](Melange_3D生化启示录_电脑键位版.apk) | 下载到手机后点击安装，这是运行游戏的模拟器。 |
| [游戏导入包](Melange导入包_修改版_高血量_本地计费成功.zip) | 解压，将其中的 `MelangeBREW` 文件夹放到手机“内部存储”中，与 `Download`、`DCIM` 等文件夹同一级。 |
| [补丁明细](修改版_补丁明细.json) | 记录游戏修改位置和修改前后的数据，供核对补丁时查阅。 |
| [SHA256.txt](SHA256.txt) | 记录 APK、游戏导入包和补丁明细的校验值，供核对下载文件时使用。 |

下载 APK 或 ZIP 时，进入对应文件页面，点击 **Download raw file（下载原始文件）** 或下载图标。

## 手机中的文件位置

解压后的文件应位于：

```text
内部存储/
└── MelangeBREW/
    ├── mif/
    │   └── 1073745158.mif
    ├── mod/
    │   └── 1073745158/
    │       ├── shenghua.mod
    │       ├── shenghua.sig
    │       ├── bin.dat
    │       ├── mbxres.bin
    │       └── map.hkm
    └── sys/
        └── breConfig.toml
```

模拟器读取这里的游戏文件。只把 ZIP 留在下载文件夹中，或放成 `MelangeBREW/MelangeBREW`，都不是上述位置。
